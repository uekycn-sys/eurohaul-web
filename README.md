# EuroHaul Web 🚛

致敬《欧洲卡车模拟 2 (ETS2)》的浏览器端 3D 重卡驾驶与货运模拟游戏。基于 **Three.js + React 18 + TypeScript + Zustand + Tailwind CSS** 从零构建，**100% 程序化几何体、纹理与 Web Audio 实时合成声浪**，无需任何外部模型、贴图或音频文件，开箱即用并全面适配 5 档画质预设。

---

## 核心特性

- **ETS2 级重卡物理与二阶空气悬挂**：
  - 900° 满舵方向盘（±450°）与非线性渐进转向曲线（中心区细腻微调、长按线性打满），支持 `N` 键一键回正。
  - 二阶欠阻尼驾驶室空气悬挂（~1.5 Hz）：刹车前倾点头与刹停回弹、换挡微幅点头、过弯离心力自然外倾。
  - 涡轮增压迟滞与收油泄压、按驱动轴载荷与湿地系数缩放的牵引力上限、按总质量缩放的 EBS 双回路气刹与热衰减、温和 ESC 电子稳定介入。
  - **12+2 速 OptiCruise / I-Shift 智能变速箱**：支持 `自动 (AT)` / `真实自动 D-N-R` / `序列手动 (MT)` 三模式切换，智能起步挡与轻中油门跳挡，智能定速巡航（下坡优先自动介入液力缓速器与排气制动控速）。
- **驾驶室沉浸感与实时 3D 车门后视镜**：
  - 物理镜像校准的左右双画中画电子镜 + 驾驶室 3D 车门实景后视镜（零额外 Render Pass），随动转向灯/缓速器拨杆、摆动顶棚挂旗、夜间驾驶室氛围灯与 `O` 键顶灯、牵引车螺旋气管（Suzie Coils）及雨天挡风玻璃动态水珠与雨刷实景刮除。
- **实时 Web Audio 声学引擎**：
  - I6 直六 / V8 750 HP 跨平面声线区分、油门负载共鸣与喷油器哒哒声、真实涡轮啸叫与泄压嘶鸣、胎噪/非铺装碎石轰鸣/湿地水花声、高速风噪、驾驶室内外声学低通隔音滤波、雨刷刮拭声、E-Toll 提示音、第五轮鞍座锁止声与雷声。
- **欧陆活态交通与高速路网 (`centralEurope`)**：
  - 4 车道高速快慢车分道（外道重卡/厢货、内道轿车）、AI 半挂拖车、动态刹车灯、鸣笛礼让；德奥高速出口 300/200/100m 倒数牌、阿尔卑斯弯道反光导向牌、四国/城入口欢迎牌、可交互自动抬杆 E-Toll 收费站与防误判红绿灯停止线。
- **中国 A2 驾考模式 & 移动端触控 HUD**：
  - 完整保留 8 项 GA/T 1028 科目二/科目三场地与道路考试（桩考倒车入库、坡道定点起步、侧方停车、单边桥、S 弯、直角转弯限宽门、山区隧道长下坡险情、科目三综合道路），以及横屏双拇指触控 HUD。

## 按键操作表

| 按键 | 功能 |
| :--- | :--- |
| `W` / `S` 或 `↑` / `↓` | 油门 / 刹车（简单自动挡下停稳继续按 `S` 自动挂倒挡；DNR 模式下 `W`/`S` 恒为油门/刹车） |
| `A` / `D` 或 `←` / `→` | 非线性渐进转向 |
| `N` | 方向盘快速回正 |
| `Space` | 驻车手刹启闭（起步前请先按 `Space` 松开手刹） |
| `Shift` / `Ctrl` | 升挡 / 降挡（真实自动模式下切换 `R - N - D`） |
| `I` / `Z` | 发动机点火熄火 / 离合器踏板（序列手动模式） |
| `Q` / `E` | 左 / 右转向灯（转弯回正后自动复位） |
| `L` / `X` (`G`) / `O` | 车灯循环（关闭→近光→远光） / 双闪警示灯 / 驾驶室顶灯 |
| `C` / `[` (`-`) / `]` (`=`) | 定速巡航启闭（≥25 km/h） / 巡航速度 -5 / +5 km/h（或恢复上次定速） |
| `B` / `J` / `U` / `Y` | 液力缓速器 (0..3) / 排气制动 / 差速锁 / 挂车手刹 |
| `T` / `H` / `P` (`K`) | 挂接与摘除半挂车 / 按住气喇叭 / 雨刮器档位循环 |
| `1` - `5` / `V` | 切换视角（驾驶室 / 追尾环顾 / 探头倒车 / 电影环绕 / 俯视） |
| `Num4` / `Num6` | 驾驶室快捷向左 / 向右观望后视镜（松开平滑回中） |
| `R` / `F7` | 服务区停车休息 8 小时（恢复精力与行车记录仪） / 呼叫 F7 道路救援拖车 |
| `M` / `Tab` / `Enter` | 欧陆全图 / 切换 Route Advisor 标签页 / 区域交互 |
| `F` / `Esc` | 全屏切换 / 关闭弹窗或返回主菜单 |
